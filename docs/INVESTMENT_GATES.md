# FelLaw — Investment Gates

Status: canonical, PR-00B · Updated: 2026-09-09
Do not raise money for FelLaw as an AI legal platform, AI lawyer, lawyer marketplace, or all-in-one legal super-app. [VALIDATED — locked decision, DECISION_LOG.md]

## Hard gates BEFORE institutional fundraising
1. Paid institutional validation: ≥2 committed paid pilots with real willingness to pay. [H01/H08]
2. Licensed/authorized fulfilment relationship executed (legal operating model + RDG sign-off). [H05/P0]
3. Real document volume on supported notice families with acceptably safe deadline performance. [H02/H06]
4. Professional handoff value demonstrated (professional need not repeat intake). [H05]
5. Repeatable institutional pipeline (≥2 accounts acquired consistently). [H01/H08]

## Pre-seed envelope
Estimated €800k–1.0M pre-seed target only after the above proofs; a lean 4-person core + specialist counsel/data/GTM can run ~€35–50k/month. Early cash need before pilots: roughly €40k–80k external for German counsel/RDG review, 100–300 professionally reviewed notice examples, professional review, user testing, narrow product refactor. [HYPOTHESIS — financial planning]

## Early cash use (if raised)
legal operating model · data/evaluation (golden set) · institution integrations · narrow product · partner network · GTM. NOT "hire 20 engineers to implement the roadmap". [HYPOTHESIS]

## Kill / reconsideration gates (company-level)
If any of the following dominates, pivot or stop rather than expand:
| Test | Kill/reconsider signal |
|---|---|
| Institutional discovery | Few target orgs see the problem as priority |
| Paid validation | Design partners like it but none pay |
| Incidence frequency | Eligible notices occur too rarely per covered population |
| Accuracy | Critical-date correctness requires unacceptable human correction |
| Coverage | Most real documents fall outside supported taxonomy immediately |
| User behavior | Users read explanations but skip next actions |
| Professional value | Lawyers redo the whole intake despite the handoff packet |
| Distribution | Institutions refuse for legal/privacy/reputational reasons |
| Economics | Human escalation dominates; automation provides little leverage |

## Funding posture
No valuation optimization before proofs. Fallback pivots (only one at a time, never both): (A) B2B "Legal Incident Intake API"; (B) one vertical execution business (e.g. employment) in the CONNY/Flightright model. [HYPOTHESIS]
