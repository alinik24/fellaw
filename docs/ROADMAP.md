# Roadmap

Candidates are ordered using user value, differentiation, evidence, leverage, time-to-test, maintenance burden, and dependency risk.

## NOW

- Stabilize the first-response workflow and ownership boundaries with offline contract tests.
- Keep the web client and agent/channel adapters on one authenticated API contract.
- Make bootstrap and doctor the supported clean-clone path.

## NEXT

- Add consent-aware, user-owned memory summaries with explicit view/export/delete controls.
- Add task-history observability for legal-boundary decisions without storing raw private transcripts.
- Package a safe OpenClaw skill that calls the Fellaw API and requires approval for consequential actions.

## LATER

- Evaluate workspace synchronization across devices using encrypted, user-controlled storage.
- Evaluate local-model routing for low-risk extraction tasks with a quality gate.

## RESEARCH

- Measure whether long-term memory improves completion without increasing privacy risk.
- Test human-approval boundaries for document submission and professional outreach.
- Compare model/provider options only through the reproducible evaluation harness.
